# LINE_UP — 표지 오브제 시안

통합과학 II 표지에서 빨간 오브제(출렁이는 띠)만 바꾼 시안 세 개. 글자, 로고,
배지, 세로 유리 줄무늬는 원본 그대로다.

| 시안 | 형태 |
| --- | --- |
| A 더블 웨이브 | 한 줄기 띠가 두 번 크게 출렁인다. 마루가 책등에 걸린다. |
| B 세 줄 물결 | 가는 띠 세 줄이 엇갈려 흐른다. 앞표지 쪽에서 세 줄이 뚜렷이 갈린다. |
| C 교차하는 두 줄기 | 두 줄기가 양쪽 표지에서 교차하고 책등에서 크게 벌어진다. |

`renders/sheet.png` 에 원본과 세 시안을 한 장에 모았다.

## 만드는 방식

1. **줄무늬 측정** — 원본의 세로 줄은 26.3 px 간격이고, 한 줄 안에서 왼쪽이
   어둡고 오른쪽으로 갈수록 밝아진다. 흰 곳에서는 거의 안 보이고 색이 짙을수록
   명암 차가 커진다. 그래서 줄 위치마다 `출력 = a × 바탕색 + b` 를 맞춰 쓴다.
2. **글자 떼어 내기** — 줄무늬가 세로라서 한 열 안에서는 바탕이 위아래로
   천천히만 변한다. 글자 상자 안의 바탕을 열마다 다항식으로 추정하고, 원본과의
   차이에서 글자의 불투명도를 구한다. 배지는 원으로 잘라 옮긴다.
3. **오브제** — 중심선과 반폭으로 정한 부드러운 띠를 겹쳐 그린다. 띠가 좁아지는
   곳(뒤집히는 곳)에 라벤더 광택을 싣는다. 색은 원본에서 뽑은
   빨강 → 크림슨 → 자주 → 라벤더.
4. 새 오브제에 1 의 줄무늬를 입히고 2 의 글자와 배지를 다시 얹는다.

책등 제목(흰 글자)은 오브제 위에 있어야 읽힌다. 세 시안 모두 책등 제목 뒤를
띠가 덮도록 위치를 잡았다.

## 사용

```
python3 build.py
```

`source/cover.png` 는 받은 표지 이미지에서 뷰어 상단 바를 잘라 낸 것이다
(2000 × 1363). 해상도가 이 이미지에 묶여 있어서 인쇄용이 아니라 방향을 고르는
용도다. 고른 안은 원본 작업 파일에서 같은 형태로 다시 그려야 한다.

형태를 바꾸려면 `variant_a` / `variant_b` / `variant_c` 의 `wave(...)` 값을
고친다. `(진폭, 파장, 위상)` 이다.
