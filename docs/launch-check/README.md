## 4. 개인정보 삭제·권리 요청 설계안 (20번)

| 단계 | 내용 |
|---|---|
| 접수 | 학생 화면 "내 정보 → 계정 삭제·정정 요청". 요청 종류는 셋으로 구분합니다. ① 계정 삭제(탈퇴) ② 정보 정정 ③ 내 정보 열람. 광고 수신거부와 결제 취소는 이 앱에 없으므로 메뉴에 넣지 않습니다 |

| 처리 범위 | 계정, 연락처, 닉네임, 포인트, 접속일, 질문·사진을 지웁니다. 성적 기록을 남길지는 운영 주체와 보존 근거를 확인한 뒤 정합니다 [법률 검토] |
| 남는 것 | 접근 기록(관리자 접속 로그)은 안전성 확보조치 기준에 따라 1년 이상 보관 대상입니다(일정 조건이면 2년). 이 점을 처리 결과 안내에 적습니다. 백업은 보관 주기가 지나면 사라지도록 하고, 그 기간을 처리방침에 적습니다 |
| 시험 | 운영 DB가 아닌 데모 DB(`seed_demo.py`)의 테스트 계정으로 끝까지 시험 → 선생님 승인 → 적용 |
