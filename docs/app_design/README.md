# 앱 화면 기준 (2026-11 확정)

앱을 만들 때 홈 화면과 기능별 화면은 이 시안을 그대로 따른다.

- 확정 이미지: `소개자료_사진/홈과_기능별/` (00 홈 + 01~12 기능별)
- 원본: `mock3.html` (만드는 스크립트 `build3.py`, 스타일 `mock.css`·`mock2.css`·`mock3.css`)
  - 글꼴 파일은 `lms/static/fonts/NotoSansKR-var.woff2` 를 이 폴더에 복사해야 브라우저에서 똑같이 보인다.
  - 아이콘(`icons.json`)·하단 탭(`tabs.html`)·로고(`logo.html`)는 실제 웹 앱에서 뽑은 것.

## 지킬 것
- 홈 한 화면에 모든 기능이 보인다: 이름·D-day → 지금 수업 → 숫자 4칸(오늘 집중·남은 과제·복습할 오답·영단어) → 기능 아이콘 12개(알림 숫자) → 성적·조교 답변 → 공지·영상 한 줄.
- 기능 12개: 공지, 시간표, 과제, 자료실, 강의 영상, 질답 게시판, 소도시 명상, 미니 Quiz, 오답 노트, 모의고사 분석, 내 성적, 내 리포트.
- 인사말·격려 문장 같은 꾸밈 문구를 넣지 않는다. 이름, 날짜, 숫자, 기능 이름만.
- 색: 소나무 초록(#2c6852, 진한 카드 #1f4d3d) 하나가 기본, 단원·장소 구분에만 하늘·보라·청록·주황·노랑.
- 예시 문제·답변은 2022 개정 통합과학 교과 범위 안에서 쓴다.
