## 1. 한눈에 보기

- **무엇인가**: 대형 재수종합반 통합과학 학습 관리 웹. 학생·강사·조교가 같은 사이트를 씁니다(휴대폰은 홈 화면에 추가해 앱처럼 사용).
- **어디서 도는가**: 시놀로지 NAS의 Container Manager(도커) 컨테이너 `student-lms`.
- **구성**

```
학생·학부모 브라우저 ──HTTPS(443)──▶ 집 공유기(443 포트포워딩) ──▶ NAS 리버스 프록시 ──▶ 컨테이너 127.0.0.1:8050
                                                                     └ /docker/student-lms/instance  ← DB·비밀키·업로드 파일 (데이터 전부)
```

- **언어·라이브러리**: Python 3.11, Flask, SQLite, waitress. 빌드 때 `requirements.txt`를 설치합니다(외부 유료 서비스 없음).
- **코드 저장소**: GitHub `jth0612-cyber/theduppp`, 작업 브랜치 `claude/tender-tesla-m6z7nj` (기본 브랜치에 아직 합치지 않았습니다. 최신 코드는 이 브랜치).

## 3. 데이터 폴더 `instance/` (가장 중요)

| 파일 | 내용 |
|---|---|
| `lms.sqlite3` | 모든 DB (학생·성적·질문·시험 결과…) |
| `.env` | `SECRET_KEY`, `FIELD_ENCRYPTION_KEY`(연락처·메모 암호화), 선택 항목(Google 등) |
| `up/` | 업로드 파일(질문 사진, 시험지 사진, 수업 노트, 자료) |
| `vapid.pem` | 앱 알림 서명 키 (잃으면 학생들이 알림을 다시 켜야 함) |

- 업데이트할 때 **이 폴더는 절대 덮어쓰지 않습니다.**
- 백업: Hyper Backup으로 이 폴더를 매일, 클라이언트 측 암호화 켜고. `FIELD_ENCRYPTION_KEY`는 NAS 밖에도 한 부.
- 폴더 권한: `Everyone 읽기·쓰기` ACL이 있어야 컨테이너(uid 1000)가 씁니다(없으면 `Permission denied: '/app/instance/.env'`로 재시작 반복).

## 4. 업데이트(새 코드 반영) 절차

1. 받은 `student-lms-update.zip`을 NAS `update` 폴더에 풉니다.
2. 풀린 내용을 `docker/student-lms`에 덮어씁니다. **`instance`는 건드리지 않음.**
3. Container Manager → 프로젝트 `student-lms` → 정지 → 정리.
4. 이미지 `student-lms-lms`를 삭제합니다(라이브러리가 바뀐 업데이트는 꼭).
5. 프로젝트 → 빌드 → 시작. 1분 뒤 접속 확인.

- DB 구조 변경은 앱이 켜질 때 자동으로 반영됩니다(`db.py`의 `init_db`).
- 켜지지 않으면: 컨테이너 → `student-lms` → **로그** 탭 맨 위 오류를 확인. 최근 사례: 학생코드 `TEST001`이 이미 있어 연습반 만들기에서 멈춤 → 수정됨(이미 있는 코드는 건너뜀, 실패해도 서버는 켜짐).

## 5. 계정

- **강사 계정 만들기**: 컨테이너 → 터미널 열기 → bash → `python create_teacher.py`.
- **조교 계정**: 강사 로그인 → '조교 계정'에서 생성. 임시 비밀번호가 한 번만 표시됩니다.
- **학생**: 반 가입 코드 또는 학생별 코드(27XXXX)로 가입 신청 → 강사가 '가입 승인'.
- **권한**: 강사·조교는 같은 관리 화면. 계정 관리(가입 승인·조교 계정·접근 기록)와 반·학생 정보 수정은 강사만.

## 6. 기능 지도 (현재)

**학생**: 홈(공지·질답·교재 구매) / 공지 / 질답 게시판(학습질문·학습상담·행정문의) / 교재 구매 / 소도시 명상(3D 공부방·집중 타이머) / 복테&모의 분석 / 수업(수업 기록·태혁쌤의 cast·시간표·자료실·강의 영상) / 공부(수능 영단어·통과 Quiz·오답 노트) / 기록(내 공부·내 성적·내 리포트·출결)

**강사·조교**: 대시보드 / 질문답변 / 1:1 첨삭 / 시험지 첨삭 / 수업 기록 / 복테·모의고사 / 반·시험 / 학생 검색 / 태혁쌤의 cast / 수능 D-day / 소도시 명상 현황 / 조교 시스템 연동 (+ 강사만: 가입 승인·조교 계정·접근 기록)

핵심 흐름:

1. **복테·모의고사** (`exams.py`, `omr.py`, `views/books.py`)
   - 복습 테스트·모의고사 각 1~50회가 미리 만들어져 있음. 회차를 열고 채점기 엑셀(OMR)을 올리면 학생 찾기(학부모 번호 뒤 8자리 = 수험번호) → 채점 → 학생 화면·통계·학부모 문자에 바로 반영.
   - 엑셀 둘째 시트 '문항정보'(단원·선지구성·보기함정·선지분석)를 채우면 합답형 보기 차이·오답 유형 분석과 단원별 성취도가 붙음.
   - 규칙 원본: 조교 시스템 인계 문서(성적 엑셀 기반 학습 유형 분석과 학부모 문자 생성). 검수 사례는 `tests/test_exams.py`.
   - 회차마다 **시험 평가**(난이도·시간·킬러 문항·총평·해설 영상) — 강사·조교 동등, 결과가 없는 학생도 봄.
   - **학부모 문자**: 회차 → '학부모 문자'에서 학생별 문구(복사·CSV). 끝에 학부모 리포트 링크가 붙음. **실제 발송은 아직 없음**(발송 서비스 미정).
   - **실장 TEST반**(가상 학생 50명)과 **[연습] 회차**(각 1~10회)로 조교가 연습. 연습 회차에는 연습반 학생만 들어가고 실제 통계와 섞이지 않음.
2. **시험지 첨삭** (`views/care.py`): 결과가 올라온 회차에서 학생이 시험지 사진을 올림 → 조교가 OMR로 틀린 문항마다 오답 유형·메모 → 학생 화면·학부모 리포트.
3. **학부모 리포트** (`/p/<비밀 링크>`, 로그인 없음): 최근 시험 득점률·변화, 단원별 성취도, 틀린 이유, 선생님 코멘트, 출결. 학생 상세 화면에서 링크 생성·교체.
4. **질답**: 학습질문(공개) / 학습상담(학생이 조교 지정, 평점, 건당 집계) / 행정문의(비공개).
5. **조교 월급 집계**: '조교 계정' 화면 월별 표·CSV — 질문 Main/부가 답변, 학습상담(건), 시험지 첨삭(건). 조교 피드백 모음 CSV(회차 → 학부모 문자 → 피드백 모음 받기).
6. **내 공부**: 공부 시간(집중 + 퀴즈 실제 푼 시간), 주간 순위, 일별 그래프, TOPIC별 진도.
7. **수업 기록**: 반별 날짜·주제·노트 사진.

## 8. 내 PC에서 고치고 시험하기

```bash
cd lms
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python seed_demo.py                       # 체험용 DB(instance/demo.sqlite3)와 로그인 정보 생성
LMS_DATABASE=instance/demo.sqlite3 flask --app app run -p 5077
python -m unittest discover tests         # 고친 뒤 꼭 실행
```

배포용 zip은 저장소 루트에서 `git archive --format=zip -o student-lms-update.zip HEAD:lms`.
