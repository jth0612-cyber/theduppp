## 재검증 (3차)

14개 중 10개 해결, 3개 일부(공지 수정, 질문 검색, 내 성적), 1개 안 됨(알림 켜기). 일부·안 됨 4개와 새로 나온 문제 중 7개를 다시 고쳤다. 알림 켜기는 테스트 브라우저가 권한 창을 띄우지 않아 끝까지 확인하지 못했다. 지금은 누르는 즉시 "권한 창에서 '허용'을 눌러 주세요"가 뜨고, 거부·실패도 버튼 글자로 남는다. 실제 휴대폰에서 한 번 확인이 필요하다.

데모가 실제 사용법과 달라서 생긴 문제도 고쳤다: 결과를 새 교재가 아니라 앱이 미리 만든 복습 테스트·모의고사 회차에 올리고, 반 '주간 테스트'를 따로 넣지 않는다. 문항정보는 테스트반 실제 양식(12칸)을 따른다.
