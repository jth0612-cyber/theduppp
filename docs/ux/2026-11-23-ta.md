화면 1280x800, 계정 ta_hanjisu. 스크린샷은 `shots/ta-01.png` ~ `ta-10.png`.

## 발견

### 1. 대시보드 첫 화면이 비어 있고 '오늘 할 일'이 한곳에 모이지 않음
- 심각도: 심각
- 어디서: 대시보드 (/t/)
- 무슨 일: 1280x800 첫 화면에는 인사말과 숫자 한 줄만 있고 나머지는 흰 여백(ta-03). '답변 대기 질문'·'최근 시험'·'담당 반' 상자는 본문 카드 바깥, 왼쪽 메뉴 아래로 밀려 전체 폭으로 깔림(ta-02). 1:1 첨삭 대기·시험지 첨삭 대기는 대시보드 어디에도 없음. 상단 요약도 '답변 대기 질문 4개'만 셈.
- 왜 문제: 하루 수십 건을 처리하는 조교가 처리할 일을 보려면 질문답변·1:1 첨삭·시험지 첨삭 세 메뉴를 따로 돌아야 함. 대시보드는 열어 봐도 쓸 정보가 없음.
- 제안: 대시보드 첫 화면에 질문·1:1·시험지 대기를 한 목록(오래된 순)으로 모으고, 상자들이 본문 영역 안에 들어가게 배치를 고친다.

### 2. '복테·모의고사' 첫 화면 회차 격자가 실제 쓰는 교재가 아님
- 심각도: 심각
- 어디서: 복테·모의고사 (/t/books)
- 무슨 일: 맨 위 '복습 테스트 1~50회 · 결과 있음 0회' 격자는 '복습 테스트'(2099년까지, 50회) 교재의 회차. 실제로 14회까지 채점이 들어간 'SEASON 1 복습 테스트'는 아래 교재 표에서 이름을 눌러야 나오고, 15회는 아직 없어 '회차 추가'를 먼저 해야 함. 교재 표에는 SEASON 1이 '등록 학생 0명'으로, 회차 표에는 14회 '채점 57명'으로, 회차 화면에는 '응시 178명'으로 나와 숫자가 서로 다름. 회차 화면 제목은 'SEASON 1' 없이 '복습 테스트 14회'.
- 왜 문제: 다음 주에 격자의 '15'를 눌러 엑셀을 올리면 학생이 보지 않는 다른 교재에 결과가 들어감. 어느 교재가 진짜인지 화면만 보고 가릴 수 없음.
- 제안: 첫 화면 격자를 현재 시즌 교재 기준으로 보여 주고, 쓰지 않는 교재는 접어 두거나 '보관'으로 표시한다. 회차 제목에 교재 이름을 붙인다.

### 3. 시험지 첨삭 메모 칸 안내문이 이미 쓴 메모처럼 보임
- 심각도: 보통
- 어디서: 시험지 첨삭 (/t/papers/15)
- 무슨 일: 메모 칸에 '4번은 개념 부족 오류입니다(2번 선지: 정의를 반대로 기억함).' 같은 회색 안내문이 들어 있음. 칸이 한 줄이라 잘려 보이고, 유형을 '자료 해석'으로 바꿔도 안내문은 '개념 부족'으로 남음. 17번 메모를 비운 채 저장해도 경고 없이 '첨삭 완료'로 넘어감. 번호 열이 좁아 '17'이 '1/7'로 줄바꿈됨(ta-06).
- 왜 문제: 빠르게 넘기다 보면 메모를 채웠다고 착각하고 빈 첨삭이 학생·학부모 리포트에 나감.
- 제안: 안내문을 짧은 예시('예: 조건 하나를 놓침')로 바꾸고, 빈 메모가 있으면 저장 전에 몇 번이 비었는지 알린다. 번호 열과 메모 칸을 넓힌다.

### 4. 같은 학생·같은 회차의 1:1 첨삭과 시험지 첨삭이 따로 쌓임
- 심각도: 보통
- 어디서: 1:1 첨삭 (/t/feedback/13), 시험지 첨삭 (/t/papers/15)
- 무슨 일: 박서윤 학생의 SEASON 1 복습 테스트 14회가 1:1 첨삭(틀린 문항 풀이 봐 주세요)과 시험지 첨삭(틀린 문항 풀이 봐 주세요) 양쪽에 대기로 있음. 두 화면은 서로를 가리키지 않음. 1:1 화면에는 질문답변 같은 인사말 틀·'다음으로 이동'이 없음.
- 왜 문제: 같은 내용을 두 번 쓰거나, 한쪽만 처리하고 다른 쪽을 놓침.
- 제안: 같은 학생·회차 요청이 있으면 서로 링크를 걸고, 한쪽에서 처리하면 다른 쪽도 닫을지 묻는다. 1:1에도 '보낸 뒤 다음 요청으로'를 넣는다.

### 5. 질문답변 메뉴에만 대기 수 배지가 없음
- 심각도: 보통
- 어디서: 왼쪽 메뉴
- 무슨 일: '1:1 첨삭 2', '시험지 첨삭 1'에는 빨간 숫자가 붙는데 '질문답변'에는 대기 4건이 있어도 숫자가 없음.
- 왜 문제: 가장 건수가 많은 일의 양을 메뉴에서 바로 볼 수 없음.
- 제안: 질문답변에도 답변 대기 수 배지를 붙인다.

### 6. 질문 목록에 과목·단원·검색이 없고 같은 문항 질문이 흩어짐
- 심각도: 보통
- 어디서: 질문답변 (/t/questions)
- 무슨 일: 필터는 유형(학습질문·학습상담·행정문의)과 상태뿐. 생명·화학 질문만 골라 볼 수 없음. 답변 완료 목록에 '[FRAMING II-22-7] 중화점 찾기'가 7건, '[Squeeze 7호-4] 판의 경계'가 6건 흩어져 있음. 자주 묻는 질문으로 고정한 글을 모아 보는 탭도 없음.
- 왜 문제: 담당 과목만 빠르게 처리할 수 없고, 같은 문항에 같은 답을 여러 번 씀. 어떤 질문을 이미 고정했는지 확인하려면 하나씩 열어야 함.
- 제안: 교재·단원(또는 과목) 필터와 제목 검색, 같은 교재 문항 묶어 보기, '자주 묻는 질문' 탭을 둔다.

### 7. 답변 완료 질문에도 답변 칸과 '다음으로 이동'이 그대로 있음
- 심각도: 보통
- 어디서: 질문 상세 (/t/questions/58)
- 무슨 일: 이미 답한 질문을 열어도 인사말 틀이 채워진 답변 칸과 '답변 등록'이 그대로 보임. 답변 옆에 뜻을 알 수 없는 'Main' 표시가 있음.
- 왜 문제: 고정하러 들어갔다가 '답변 등록'을 누르면 인사말만 있는 두 번째 답변이 올라감.
- 제안: 답변 완료 상태에서는 답변 칸을 접고 '추가 답변 쓰기' 버튼으로 연다. 'Main'은 뜻이 보이는 말로 바꾸거나 뺀다.

### 8. 조교 화면에 '계정 삭제'·'교재 정보 수정 · 삭제'·'결과 모두 지우기'가 보임
- 심각도: 보통
- 어디서: 학생 상세 (/t/students/79), 교재 (/t/books/3), 회차 (/t/mocks/127)
- 무슨 일: 조교는 학생 영구 삭제·교재 삭제를 못 하는 것으로 알고 있는데 학생 상세에 '계정 삭제', 교재 화면에 회차마다 '삭제'와 '교재 정보 수정 · 삭제', 회차 화면 맨 아래에 '결과 모두 지우기'가 보임. 누르면 무엇이 되는지는 확인하지 않음(누르지 않음).
- 왜 문제: 권한이 막혀 있다면 눌렀다가 오류를 보고, 막혀 있지 않다면 조교가 되돌릴 수 없는 삭제를 할 수 있음.
- 제안: 조교에게 허용되지 않은 버튼은 숨기고, 허용된 삭제는 무엇이 지워지는지와 되돌릴 수 있는지를 확인창에 적는다.

### 9. 새 회차 기본값이 기존 회차와 다름
- 심각도: 보통
- 어디서: SEASON 1 복습 테스트 '회차 추가' (/t/books/3)
- 무슨 일: 1~14회는 모두 20문항·40점인데 15회 추가 칸 기본값은 25문항·50점. 연습 회차 화면은 '엑셀을 올리면 문항 수·정답·배점이 정해집니다'라고 하는데 실제 교재는 회차 추가 때 정답을 따로 적게 되어 있어 어느 쪽이 맞는지 헷갈림.
- 왜 문제: 기본값 그대로 추가하면 배점이 틀린 회차가 생김.
- 제안: 직전 회차의 문항 수·만점을 기본값으로 쓰고, 정답을 엑셀에서 읽는지 직접 적는지 한 가지로 맞춘다.

### 10. 수업 기록을 올리면 반 선택이 처음으로 돌아가고 올린 노트를 볼 수 없음
- 심각도: 보통
- 어디서: 수업 기록 (/t/lessons)
- 무슨 일: 대구 토요일 A반으로 올린 뒤 반이 '대구 재종 1반', 날짜가 오늘로 돌아감. 아래 목록은 8개 반 112줄이 섞여 있고 반 필터가 없음. 목록에서 노트 사진을 열어 볼 수 없고, 파일을 골라도 미리보기가 없음. 주차는 주제 칸에 직접 적어야 함.
- 왜 문제: 여러 반을 이어 올릴 때마다 반을 다시 골라야 하고, 잘못 올렸는지 확인할 방법이 없음.
- 제안: 마지막에 고른 반을 기억하고, 목록에 반 필터와 노트 보기 링크, 사진 미리보기를 둔다.

### 11. 임시 비밀번호에 복사 버튼이 없음
- 심각도: 사소
- 어디서: 임시 비밀번호 화면 (/t/students/79/account)
- 무슨 일: '이 화면은 다시 볼 수 없습니다' 안내와 함께 아이디·비밀번호가 큰 글씨로 나오지만 복사 버튼이 없음(ta-07).
- 왜 문제: 오픈채팅에 붙여 넣으려면 드래그해서 복사해야 하고, 한 번 닫으면 다시 볼 수 없음.
- 제안: 아이디·비밀번호를 한 번에 복사하는 버튼을 둔다.

### 12. 작은 표시 문제
- 심각도: 사소
- 어디서: 여러 화면
- 무슨 일: 어느 화면에서든 '뒤로'가 대시보드로 감(질문 상세에서 눌러도 질문 목록이 아님). 대시보드 인사가 '한지수 선생님', 마지막 로그인이 '2026-11-23T01:21:51'처럼 T가 들어간 형식. 1:1 첨삭의 '4번(2, 정답 1, 고른 답 2)'에서 앞의 2가 배점인지 알기 어려움. 학생 검색 첫 쪽에 실장 TEST반 가상 학생이 실제 학생과 섞여 나오고 반 필터가 없음.
- 왜 문제: 하나하나는 작지만 처리 속도를 조금씩 늦춤.
- 제안: '뒤로'는 직전 목록으로, 호칭은 '조교', 시각은 '11-23 01:21' 형식, 배점은 '2점'으로 적고, 학생 검색 기본값에서 TEST반을 뺀다.
