## 다룬 내용
- 토스증권이 초보 투자자 앞의 "벽"을 하나씩 낮춘 과정(01:00).
- 낯섦: 회사명 옆에 익숙한 브랜드 로고를 붙이고, 음악·쇼핑 앱 같은 UI를 씀(02:05).
- 정보: 자체 업종 분류(TICS), 업종 이미지 236개, 시가총액·매출·영업이익 정렬(03:07).
- 알림: 한 줄 안에 이해되게 한자어를 빼며 문구를 고침(05:28). 위험 종목은 "레드플래그" 영역과 거래 전 재확인(06:55).
- 주문: 수량만 넣는 화면, 시간대에 따라 예약/일반 주문 자동 전환, 부족한 돈 자동 충전(08:01~10:08).

## 가져올 규칙
- 낯선 항목 이름 옆에는 사용자가 아는 기호(교재 표지, 과목 아이콘, 선생님 사진)를 붙인다(02:19).
- 새로 만드는 화면은 학생이 매일 쓰는 앱(메신저, 쇼핑)과 비슷한 조작 방식을 따른다(02:48).
- 외부에서 가져온 어려운 분류명(교육과정 코드, 성취기준 번호)은 쉬운 말로 다시 묶어 보여준다(03:40).
- 그림으로 설명이 안 되는 항목에만 짧은 설명 문장을 붙인다(04:10).
- 상세 화면 머리는 경로, 제목, 개수, 두 줄 설명과 "더보기" 순서로 쌓고, 긴 설명은 접어 둔다(004-38 화면).
- 순위 목록에는 정렬 기준 탭과 데이터 기준 시각(예: "오늘 8:00 기준")을 함께 표시한다(004-15, 004-38 화면).
- 목록은 나열만 하지 말고 왜 이 항목이 여기 있는지 한 줄 이유를 붙인다(예: "오답 3회 이상")(04:55).
- 알림은 한 줄로 끝나게 쓰고, 약어와 한자어를 빼고 해요체로 마무리한다(05:47~06:21, 006-34 화면).
- 알림 문구는 팀원이 직접 받아 보고 고친 뒤 확정한다(06:12).
- 되돌리기 어려운 행동(과제 삭제, 반 이동, 성적 확정) 전에는 위험 상태를 눈에 띄는 영역으로 먼저 알리고 한 번 더 묻는다(07:23~07:50).
- 마감 시간이 있는 기능은 시간대별 상태표를 먼저 만들어 기획·개발·QA가 같은 표를 보고, 버튼 하나가 시간에 따라 "제출"과 "지각 제출"로 바뀌게 한다(08:45~09:27).
- 입력은 꼭 필요한 값 하나로 줄인다(예: 출결 화면에서 학생만 고르면 날짜·반은 자동)(08:25).
- 사용자가 미리 해 둬야 했던 준비 단계(포인트 충전 같은)는 시스템이 대신 처리한다(09:44~10:02).
