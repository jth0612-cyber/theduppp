## 가져올 규칙
- 그림이나 일러스트는 배경이 투명한 형식(PNG, APNG, SVG)으로 만들어 라이트와 다크 모드에 한 벌로 쓴다 (04:14)
- 다크모드는 순검정 바탕보다 짙은 회색 카드 위에 같은 구조를 그대로 옮긴다. 레이아웃은 모드마다 따로 만들지 않는다 (002-08 화면)
- 다크모드 배경색이 기기마다 달라 보일 수 있으니, 그래픽에 배경색을 굽지 말고 화면 배경에 맡긴다 (03:53)
- 한 화면에는 질문형 제목 하나와 입력 또는 선택 하나, 하단 주 버튼 하나만 둔다 (002-08 화면)
- 선택을 미룰 수 있는 화면은 회색 보조 버튼과 파란 주 버튼을 나란히 둔다(예: "다음에 / 확인") (002-08 화면)
- 기능 소개 화면은 그래픽 여러 장 대신 한 영역에서 스크롤에 따라 내용이 바뀌는 방식으로 공간을 아낀다 (06:23)
- 스크롤을 멈춰도 소개 애니메이션은 반복 재생되게 해서 화면이 멈춘 것처럼 보이지 않게 한다 (06:44)
- 같은 종류 배너가 색만 다르게 반복되는 목록에서는 그래픽을 배너 색과 분리해 하나만 관리한다 (05:18)
- 아이콘과 일러스트는 분류별 자산 페이지 한 곳에 모으고, 화면이 같은 주소를 직접 불러오게 해서 따로 동기화하지 않는다 (07:43)
- 홈 상단 배너에 학생 이름을 넣은 짧은 인사("OO님, 생일 축하해요!")를 쓸 수 있다 (001-31 화면)
- 소개 화면 제목은 두 줄 이하로 쓰고, 문제를 짚는 부제는 작은 회색 한 줄로 위에 둔다 (002-41 화면)
