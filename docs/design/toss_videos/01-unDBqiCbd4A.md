## 가져올 규칙
- 학생이 요청하지 않은 자동 기록(시스템 출석 체크, 자동 지급 포인트 등)은 학생 활동 목록에 한 줄씩 끼우지 말고 별도 탭이나 하루 단위 한 줄로 묶는다. (09:33)
- 자동 이벤트마다 푸시를 보내지 않는다. 같은 종류는 하루 한 번으로 묶고 알림 설정에서 끌 수 있게 한다. (09:39)
- 자동화 기능에는 학생이나 교사가 직접 켜고 끌 수 있는 선택지를 남긴다. 기본값을 자동으로 두더라도 수동 전환을 막지 않는다. (10:19)
- 한 화면의 주인공은 숫자 하나와 버튼 하나로 정한다. 예: 과제 카드에는 마감일과 "제출하기"만 두고, 배점, 채점 기준, 첨부 규칙은 바텀시트 상세로 보낸다. (11:48)
- 버튼 문구는 지금 할 행동으로 쓴다. 주기나 기능명("매일 ~", "~ 서비스") 대신 "지금 제출하기", "바로 확인하기"처럼 동사로 끝낸다. (12:32)
- 제출 완료처럼 기다리던 결과가 나오는 순간에 짧은 축하 모션을 넣는다. 1초 안팎으로 끝내고, 동작 줄이기 설정이면 생략한다. (12:13)
- 처음 보는 기능 버튼은 사용자가 손해를 걱정해 망설인다. 버튼 바로 아래에 "이걸 하면 뭐가 좋은지" 텍스트 링크를 두고 짧은 설명 페이지로 연결한다. 팝업으로 강요하지 않는다. (15:20, 16:00)
- 버튼을 눌러도 되돌릴 수 있거나 불이익이 없으면 그 사실을 버튼 근처에 한 줄로 적는다(예: "제출 후 마감 전까지 다시 고칠 수 있어요"). (14:41)
- 공유하거나 자랑할 화면은 숫자를 생활 속 비유로 바꿔 보여 준다. 예: "단어 300개 외움" 옆에 "교과서 한 단원 끝"처럼 구간별 문구를 정해 둔다. 공유 화면에는 개인 점수가 노출되지 않는다고 안내한다. (04:40)
- 새 기능을 만들 때 첫 진입 안내(공지 배너, 설명 페이지)를 같은 일정 안에 설계한다. 출시 후에 따로 만들지 않는다. (19:33)
- 권한이나 학년 때문에 막히는 화면은 막고 끝내지 않는다. "어떤 기능을 가장 먼저 쓰고 싶은지" 선택형 질문 하나를 붙여 수요를 모은다. (32:38)
- 학생용 화면의 메뉴 이름은 학생이 평소 쓰는 말로 바꾼다. 송금을 "돈 보내기", 소비를 "용돈기입장"으로 바꾼 것처럼, 예: "평가 결과"를 "내 점수", "학습 이력"을 "공부한 기록"으로 쓴다. (36:38)
- 메뉴 이름뿐 아니라 가입, 제출, 오류 안내 같은 단계별 안내 문구도 같은 기준으로 쉬운 말로 다시 쓴다. (37:19)
- 대상 연령은 "만 7세 이상"처럼 쓰지 말고 "초등학생부터"처럼 학년으로 표기한다. 같은 반인데 생일로 갈리는 기준은 피한다. (28:40, 29:18)
- 학생이 혼자 보는 영역(개인 메모, 오답 노트 등)과 보호자·교사에게 보이는 영역을 나누고, 보호자에게는 전체 내역 대신 위험 신호(장기 미접속, 연속 미제출) 알림만 보낸다. (29:18, 31:18)
- 첫 출시는 가장 많이 요청한 기능 하나로 시작한다. 이후 요청을 1~10위로 공개하고 각 항목에 "만드는 중", "출시됨" 상태를 붙여 갱신한다. (33:20, 35:16)
- 의견은 별도 설문 페이지가 아니라 해당 화면 맥락 안에 짧은 질문으로 넣어 받는다. (39:25)
- 선택지가 많은 고르기(교재, 반, 학습 코스)는 목록 나열 대신 질문 2개로 추천안 하나를 보여 준다. 첫 화면에 "질문 2개에만 답하면 돼요"처럼 질문 수를 미리 밝힌다. (54:06, 55:10)
- 추천 질문 첫 번째는 "지금 쓰는 것"을 묻는다. 사람은 현재 쓰는 것과 비슷한 것을 고르므로, 현재 수준이나 지금 보는 교재를 먼저 묻고 그 근처를 추천한다. (53:25, 54:06)
- 목록으로 보여 줘야 할 때는 항목마다 제목 한 줄과 회색 보조 설명 한 줄만 둔다. (52:30)
- 초등학생 대상이라도 캐릭터와 귀여운 장식을 기본으로 깔지 않는다. 설문에서 81%가 심플하고 세련된 쪽을 골랐다. 흑백 같은 단순한 색을 기본으로 둔다. (68:52, 73:32)
- 어린 사용자 대상 디자인을 고를 때는 시안 전체 투표 대신 축을 나눠 묻는다(심플 대 화려, 그래픽 종류, 색). 같은 디자인에 색만 바꾼 비교처럼 한 번에 한 가지만 다르게 한다. (71:43, 72:12)
- 새 색이나 아이콘은 목업 소재 말고 실제 앱 화면 여러 장에 얹어 보고 정한다. (86:09, 94:46)
