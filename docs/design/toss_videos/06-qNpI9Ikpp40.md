# 토스ㅣSimplicity 23 - 오늘도 문제를 해결하고 있을 모든 디자이너에게
YouTube: qNpI9Ikpp40

## 다룬 내용
- 1분 10초 남짓한 Simplicity 23 예고 영상. 23개 세션의 짧은 발언을 이어 붙임 (00:00)
- 쉽고 간편한 경험을 만들수록 속았다, 못 믿겠다, 정보가 샐까 불안하다는 반응도 쌓인다는 발언 (00:00)
- 이자를 한 달에 한 번이 아니라 더 자주, 매일 주면 어떨까라는 발상 전환 (00:19)
- 처음 하는 일이 많아 왜 해야 하는지 공감대를 만들려고 지점토 모형을 만든 사례 (00:38)
- 사용자가 생각하지 않고 본능적으로 쓸 수 있어야 한다는 원칙을 온라인 사업자 리서치에서 지키지 못하고 있었다는 발언 (00:57)

## 화면에서 본 것
- 000-00: 자막형 슬라이드 "쉽고 간편한 경험" 부분에 빨간 물결 밑줄. 같은 문장 아래 부정적 반응이 이어짐
- 000-10, 000-32: 추상 그래픽과 모션 블러 전환 장면(내용 없음)
- 000-20, 000-43: 노란 강조 글자가 섞인 자막이 흐리게 전환되는 장면
- 001-00: 말풍선형 자막 "사용자가 생각하지 않고 본능적으로 쓸 수 있어야" 한다는 원칙 문장
- 001-09: 마지막 자막 "오늘도 문제를 해결하고 있을 모든 디자이너에게 공감과 영감이 되기를 바라며 전하는 23개의 이야기"

## 가져올 규칙
- 과정을 줄여 쉽게 만들수록 사용자가 무엇에 동의했는지, 정보가 어디에 쓰이는지 한 줄로 분명히 알려 신뢰를 지킨다 (00:00)
- 화면은 학생이 설명을 읽지 않고도 다음 행동을 알 수 있게 만든다. 새 화면마다 처음 보는 사람에게 말없이 써 보게 해서 확인한다 (01:02)
- 매주 한 번 같은 주기 알림(예: 주간 학습 리포트)이 정말 그 주기여야 하는지 따져 보고, 더 자주 짧게 주는 방식도 검토한다 (00:19)
