- 007-08: 고칠 단어를 빨간색으로 표시한 예시 "유저라면 쓸 수 있어요", "실명을 알려주세요", "오류가 생겼어요"
- 007-55: 규칙 시트. Before, After, Category 열. 예: "(이용)했어요, (이용)됐습니다" 같은 과거형 변형을 "썼어요, 쓰셨네요"로, 현재형 "(이용)해요, (이용)됩니다"를 "쓸 수 있어요, 써요"로

- 009-18: 완료 화면 가운데 아이콘과 두 줄 "6,000,000원을 송금했어요"

## 가져올 규칙
- 같은 동작은 앱 전체에서 한 가지 말로만 쓴다. "제출 완료", "제출했습니다" 대신 "제출했어요" 하나로 정한다 (01:51)
- 같은 기능을 화면마다 다른 이름으로 부르지 않는다(예: "간편 인증"과 "자동 인증"을 섞지 않음) (03:49)
- 문장은 "~했어요", "~할 수 있어요" 같은 해요체로 맞춘다 (06:27, 007-55 화면)
- 한자어 명사는 쉬운 동사로 푼다. "개설"은 "만들다", "가능"은 "할 수 있다", "납부"는 "냈어요" (07:11)
- 바로 바꿀 단어표를 둔다. 유저는 사용자, 실명은 이름, 오류는 문제, 전월은 지난달, 당월은 이번 달, 최초는 처음, 동일은 같은 (07:11, 008-13 화면)
- "즉시", "바로"처럼 빼도 뜻이 같은 부사는 지운다 (008-13 화면)
- 에러 문구에는 "오류" 대신 "문제"를 쓴다. 예: "문제가 생겼어요" (07:11)
- 문구 규칙은 문서로만 두지 말고, 입력할 때 틀린 단어를 표시하고 추천어를 보여 주는 검사기로 만든다 (05:25, 008-48 화면)
- 규칙 표는 스프레드시트 한 곳에서 관리하고, 추가하면 배포 없이 바로 반영되게 한다 (08:10)
- 화면 문구 오류(띄어쓰기, 마침표)를 누구나 제보할 수 있는 채널을 연다 (03:33)
- 학생의 기쁜 순간(목표 달성, 연속 출석, 생일)을 찾아 짧은 축하 문장을 보낸다 (09:59)
- 오래 불편했던 점을 고쳤다고 알릴 때는 결과만 말하지 말고 "그동안 불편하셨죠" 같은 공감 한 문장을 앞에 붙인다 (10:39)
- 개인정보 동의 화면에는 사용자가 걱정할 점을 먼저 짚는 한 줄을 넣는다(예: 다른 곳에 쓰지 않는다는 약속) (11:14)
- 종료나 해지 같은 결정 화면에는 결과를 한 줄로 알리는 설명을 제목 아래 둔다(예: 종료되면 정보가 더 이상 제공되지 않음) (008-48 화면)
- 이유를 묻는 화면은 짧은 해요체 선택지 4~5개와 "다른 이유"를 체크 목록으로 준다 (008-48 화면)
- 완료 화면은 금액이나 대상이 들어간 두 줄 문장 하나와 아이콘만으로 끝낸다 (009-18 화면)
- 목록은 최근 2~3개만 보여 주고 아래에 "상세 보기" 텍스트 링크를 둔다 (008-30 화면)
