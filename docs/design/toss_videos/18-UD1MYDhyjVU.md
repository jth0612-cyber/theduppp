## 가져올 규칙
- 결과가 계속 0이거나 나쁜 시기에는 매일 가는 자동 알림을 멈춘다. 예: 휴강 기간에는 "오늘 학습 0분" 알림을 보내지 않는다(01:51).
- 고정 비용이나 시간을 쓰는 항목은 항목별로 성과를 따로 보여준다. 예: 수강 중인 강좌별로 출석률과 점수 변화를 나눠 보여준다(03:13).
- 추천은 사용자가 이미 고른 것과 비교해 "지금보다 나은 것"으로 제시하고, 거리나 난이도 같은 부담 요소를 함께 적는다(04:17, 05:22 화면).
- 추천 순위는 효과 하나만 보지 말고 부담 지표(거리, 소요 시간)를 섞어 정한다(05:10).
- 기능을 만든 뒤 사용자 조사를 다시 나가, 사용자가 기능을 예상 밖으로 쓰는 방식을 다음 기능의 근거로 삼는다(03:24~03:32).
