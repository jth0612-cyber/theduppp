## 가져올 규칙
- 위험이나 이상 상태는 글보다 아이콘 색으로 먼저 알린다. 예: 제출물 표절 의심이면 이름 앞에 빨간 아이콘, 정상이면 파란 아이콘(03:06).
- 경고에는 근거를 붙인다. "위험해요"만 쓰지 말고 출처와 숫자를 같이 보여준다(03:53~04:04).
- 위험한 행동은 경고만 하지 말고 진행 전에 작은 확인 시트를 띄워 막는다(04:42).
- 경고 문구는 어떤 나이대도 한 번에 알아보게 쉬운 말과 그림을 함께 쓴다(03:25~03:34).
- 시스템 사정으로 지금 못 하는 일은 거절하지 말고 예약해 두었다가 끝나면 처리하고 알린다. 예: 점검 중 제출을 받아 두고 점검 후 반영(06:11~06:27).
- 기다리는 상태 안내는 딱딱한 시스템 말 대신 부드러운 한 줄로 바꾸고, 끝나면 "제출 잘 됐어요"처럼 결과를 알린다(06:41~06:48).
- 사용자가 몰라도 되는 내부 규칙(은행별 점검 시간 같은 것)은 나열해 보여주지 않는다(05:57).
- 자주 쓰는 기능은 몇 단계 돌아가지 않게 탭이나 첫 화면으로 꺼내 둔다(07:13~07:30).
- 많이 쓰는 기능의 위치를 옮길 때는 프로토타입으로 오래 테스트하고 단계적으로 배포한다(07:46~08:10).
- 여러 페이지로 쌓이던 입력 흐름은 가능하면 한 페이지 안에서 끝낸다(08:22~08:26).
- 단계마다 도는 로딩을 최소로 줄인다(08:29).
- 흐름 중간에 튀어나오는 다이얼로그를 없애고, 에러는 그 자리 화면에서 글을 안 읽어도 알 수 있게 보여준다(08:45~08:58).
- 에러와 알림 문구를 케이스별로 표 하나에 모아(케이스, 채널, 대상, 문구, 적용 여부) 같은 톤으로 다듬는다(08:33 화면).
- 알림 문구 첫 줄에는 핵심 값(점수, 마감일)을 먼저 쓰고 변수로 채운다. 예: "{{score}}점 채점 완료"(08:33 화면).
- 어디서 시작하든 같은 완료 화면으로 끝나게 해 "끝났다"를 한 번에 알게 한다(09:02~09:11).
- 주 행동 버튼은 화면 아래 꽉 찬 너비 버튼 하나로 둔다(08:45 화면).
- 보내기 대상 목록은 "내 계좌"와 "최근"처럼 묶고, 자주 쓰는 대상에 즐겨찾기 별을 단다(08:22 화면).
