## 가져올 규칙
- 버튼, 입력창, 탭은 디자인 시안 단계부터 실제 동작하는 컴포넌트로 확인한다. 정적 그림만 보고 스펙을 정하지 않는다 (04:43)
- 탭이나 목록 제목이 길어질 때 말 줄임 위치와 최대 줄 수를 컴포넌트 규칙으로 정해 둔다 (02:44)
- 색은 "grey-500" 같은 토큰 이름 하나로만 부르고, 같은 색에 여러 이름이 생기지 않게 한다 (01:48)
- 숫자 뒤에 원, 억 같은 단위가 붙으면 자동으로 천 단위 콤마를 찍는다. 학생 점수나 수강료 표시에 같은 규칙을 쓴다 (05:54)
- 쓰지 않을 단어 목록을 스프레드시트로 관리하고, 화면 문구를 넣을 때 자동으로 걸러 경고한다 (06:15)
- 입력값을 다시 보여 줄 때는 "입력한 내용을 확인해주세요" 같은 한 줄 제목 아래 라벨과 값을 세로로 나열한다 (005-15 화면)
- 인증번호처럼 짧은 숫자 입력은 칸을 나눠 보여 주고 숫자 키패드를 바로 띄운다 (05:05)
- 에러 상태의 도움말은 회색이 아니라 에러 색으로 표시한다. 상태별 색을 컴포넌트에 고정한다 (03:45 화면)
- 기본 본문 글자색은 순검정 대신 진한 회색 한 단계(예: Grey 700)로 정해 둔다 (03:45 화면)
- 컴포넌트 미리보기에 다크 테마 전환을 넣어 두 모드를 함께 확인한다 (02:59 화면)
- 새 도구나 규칙을 도입하면 사용자 온보딩 세션을 여러 번 열고, 문제 목록을 한곳에 모아 처리한다 (03:42)
