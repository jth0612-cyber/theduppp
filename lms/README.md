# 학습 관리 (강사 개인용)

재수종합반 담당 반 학생들의 성적·학습 메모·질문답변·공지·자료를 관리하는 웹앱입니다.

## 처음 설치 (Windows)

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python create_teacher.py
.venv\Scripts\python app.py
```

브라우저에서 http://127.0.0.1:5000 접속.

처음 실행하면 `instance/.env` 에 비밀키와 **암호화 키(FIELD_ENCRYPTION_KEY)** 가 생성됩니다.
이 키를 잃어버리면 암호화된 연락처·메모를 복구할 수 없으니 USB 등 다른 곳에 따로 보관하세요.

## 데모로 먼저 둘러보기

```
.venv\Scripts\python seed_demo.py
set LMS_DATABASE=instance\demo.sqlite3
.venv\Scripts\python app.py
```

로그인 정보는 `instance/DEMO_CREDENTIALS.txt` 에 있습니다. 데모 DB는 실제 DB(`lms.sqlite3`)와 분리돼 있습니다.

## 주요 기능

- **반**: 반 만들기, 보관(종강)
- **학생**: 개별 등록 / CSV 일괄 등록(`이름,수험번호,연락처,목표,메모`), 반 이동, 퇴원, 영구 삭제(개인정보 파기)
- **시험·성적**: 시험 등록 → 표에서 점수 입력(Enter 로 다음 칸), 평균·표준편차·석차, CSV 내보내기
- **학생 상세**: 성적 추이 그래프, 반 평균·석차, 학습·상담 메모(암호화)
- **질문답변**: 학생이 사진과 함께 질문 → 강사가 답변, 답변 후 다음 질문으로 자동 이동
- **공지·자료**: 반별 공지, PDF/PPT/HWP 등 자료 업로드
- **학생 계정**: 수험번호가 아이디. 반 단위 일괄 발급(임시 비밀번호 CSV 1회 다운로드), 첫 로그인 시 비밀번호 변경 강제
- **접근 기록**: 로그인, 학생 열람, 수정, 다운로드, 내보내기 기록
- **학생 회원가입**: 반마다 8자리 가입 코드(새로 만들기·가입 멈추기 가능). 학생이 코드로 신청 → 강사가 '가입 승인'에서 승인해야 로그인 가능. 명단에 같은 수험번호가 있으면 그 학생과 연결
- **조교 계정**: 강사가 '조교 계정' 메뉴에서 생성·비밀번호 초기화·사용 중지. 조교는 질문답변 화면만 사용(학생 연락처·메모·성적 접근 불가), 답변은 "조교 답변 (이름)"으로 표시
- **질답 게시판**: 학습질문(전체 공개, 닉네임 표시, 사진 필수) / 행정문의(본인·선생님만). 답변 후 추가 질문 2회
- **공지 말머리**: 공지·정오·일정·시험·자료. '정오'는 학생 화면 정오표 탭에 교재별로 모임
- **강의 영상**: 파일 대신 유튜브(일부 공개)·비메오·구글 드라이브 링크 + 만료일
- **교육 뉴스**: 선생님이 올린 기사 링크가 학생 홈에 카드로 표시
- **접속 기록**: 하루 첫 접속을 기록해 이번 주 접속 칸과 연속 접속일을 보여 줌
- **미니게임**: 염기 짝 맞추기(A–T, G–C), 샤가프 법칙 계산, 통합과학 퀴즈(단원별 문제은행). 정답은 서버에만 저장·채점

## 보안 설계

| 위협 | 대응 |
|---|---|
| 비밀번호 유출 | argon2id 해시, 10자 이상 + 2종류 문자, 임시 비밀번호는 저장하지 않고 1회만 표시 |
| 무차별 대입 | 계정별 5회 실패 시 15분 잠금 + IP별 5분 20회 제한, 존재하지 않는 계정도 같은 응답 |
| 권한 우회 / 남의 정보 열람(IDOR) | 모든 강사 화면은 서버에서 역할 확인, 학생 조회는 항상 `본인 id` 조건 포함, 남의 질문·파일은 404 |
| 세션 탈취 | HttpOnly·SameSite 쿠키, 로그인 시 세션 재발급, 60분 미사용 시 만료, 로그인 화면 캐시 금지 |
| CSRF | 모든 POST 에 CSRF 토큰 (Flask-WTF) |
| XSS | 템플릿 자동 이스케이프 + CSP(`default-src 'self'`, 인라인 스크립트 금지) |
| SQL 인젝션 | 모든 쿼리 파라미터 바인딩 |
| 악성 파일 업로드 | 확장자 화이트리스트 + 파일 시그니처 검사, 무작위 이름으로 웹 루트 밖 저장, 권한 확인 후 다운로드 |
| DB 파일 유출 | 연락처·메모·상담 기록은 Fernet(AES) 암호화 저장 |
| CSV 수식 주입 | 내보내기 시 `= + - @` 로 시작하는 값 무력화 |
| 오픈 리다이렉트 | 로그인 후 이동 주소는 내부 경로만 허용 |

## 학생에게 공개하기 (시놀로지 NAS)

**[SYNOLOGY.md](SYNOLOGY.md)** 에 단계별 안내가 있습니다. 요약하면:

1. Container Manager 로 `docker-compose.yml` 프로젝트 실행 (앱은 NAS 내부 127.0.0.1:8050 에서만 열림)
2. DDNS + Let's Encrypt 인증서, 리버스 프록시(HTTPS 443 → localhost:8050)
3. `instance/` 폴더를 Hyper Backup 으로 암호화 백업, 암호화 키는 NAS 밖에도 보관
