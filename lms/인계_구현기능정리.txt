1. 한눈에 보기
==================================================
- 용도: 시대인재N 재수종합반에서 강사 본인이 들어가는 반(A, B, C, ... K, P 등) 학생들의 학습 관리
- 과목: 통합과학
- 규모 목표: 학생 약 1000명
- 운영 형태: 강사 1명 개인용(여러 학원·강사가 나눠 쓰는 구조 아님)
- 기술: Python 3.11, Flask 3.1, SQLite, Jinja 템플릿, 순수 JS/CSS, waitress, Docker
- 현재 상태: 기능 구현 완료, 이 PC에서만 실행 중. NAS에는 아직 올리지 않음
- 코드는 git 저장소가 아님

==================================================
2. 사용자 역할
==================================================
[강사 teacher]
- 모든 강사 화면 사용. 계정은 서버에서 create_teacher.py 로 생성

[조교 assistant]
- 질문답변 화면만 사용(목록, 상세, 답변, 답변 대기로 되돌리기, 첨부 사진 보기, 행정문의 포함)
- 질문한 학생의 이름·반은 보임. 학생 상세, 연락처, 메모, 성적, 반 관리, 접근 기록 등은 403
- 강사가 '조교 계정' 메뉴에서 생성. 임시 비밀번호 1회 표시, 첫 로그인 때 변경 강제

[학생 student]
- 학생 화면만 사용. 수험번호가 로그인 아이디
- 계정 생성 경로 2가지: 강사 발급(임시 비밀번호) 또는 회원가입(반 코드 + 강사 승인)

3. 강사 화면 기능 (/t/...)
==================================================
[대시보드]
- 담당 반 수, 재원 학생 수, 답변 대기 질문 수, 시험 수
- 답변 대기 질문, 최근 시험, 담당 반 목록, 학생 검색창

[반 관리]
- 반 만들기, 이름·설명 수정, 보관(종강), 보관된 반 보기
- 반 상세 탭: 학생 / 시험·성적 / 공지 / 자료실 / 강의 영상

[학생 관리]
- 개별 등록, CSV 일괄 등록(UTF-8, CP949. 열: 이름,수험번호,연락처,목표,메모. 앞 2개 필수. 최대 5MB)
- 이름·수험번호 검색, 페이지 나누기(50명 단위)
- 학생 상세: 성적 추이 그래프, 시험 기록(점수, 득점률, 반 평균, 석차), 학습·상담 메모(분류 포함), 질문 기록
- 정보 수정, 반 이동, 퇴원 처리, 영구 삭제(이름을 입력해야 실행)
- 계정 발급, 비밀번호 초기화, 계정 삭제, 반 단위 계정 일괄 발급(임시 비밀번호 CSV 1회 다운로드)
- 포인트 수동 지급(-1000 ~ 1000, 사유 필수), 누적 접속일과 보유 포인트 확인

[시험·성적]
- 시험 등록(이름, 과목, 날짜, 만점), 표에서 점수 입력(Enter로 다음 칸)
- 평균, 표준편차, 최고, 최저, 석차 자동 계산, CSV 내보내기, 시험 삭제

[질문답변] (조교도 사용)
- 상태(대기/완료/전체), 유형(학습질문/행정문의) 필터
- 답변 등록, 다음 대기 질문으로 자동 이동, 답변 대기로 되돌리기
- 답변과 학생 추가 질문을 시간순 대화로 표시

[공지]
- 말머리: 공지, 정오, 일정, 시험, 자료. 정오표용 교재명 입력, 삭제

[자료실]
- PDF, PPT, PPTX, DOCX, HWP, PNG, JPG 업로드(최대 20MB), 파일 형식 배지, 삭제

[강의 영상]
- 영상 파일은 서버에 올리지 않고 링크로 등록(유튜브, 비메오, 구글 드라이브만 허용)
- 제목, 길이, 만료일(선택). 유튜브는 썸네일 표시

[교육 뉴스]
- 제목, https 링크, 출처, 한 줄 요약 등록. 전체 학생 홈에 최근 4개 카드 표시

[학생 가입 관리]
- 반마다 8자리 가입 코드. 새 코드 만들기, 가입 받기/멈추기
- '가입 승인' 메뉴: 대기 건수 표시, 선택 승인·거절, 전체 승인
- 명단 대조 표시(명단에 없음 / 일치 / 이름 다름 / 다른 반). 명단에 같은 수험번호가 있으면 그 학생에 계정 연결

[조교 계정]
- 생성, 비밀번호 초기화, 사용 중지/다시 사용, 답변 수와 최근 접속 확인

[접근 기록]
- 로그인, 학생 열람·수정, 파일 다운로드, 내보내기, 승인 등 작업 기록과 IP

4. 학생 화면 기능 (/s/...)
==================================================
[회원가입 /signup]
- 반 코드, 이름, 수험번호, 비밀번호, 개인정보 수집·이용 동의(필수)
- 승인 전 로그인 시 "승인 대기" 안내

[홈]
- 누적 접속일, 연속 접속일, 이번 주 7칸, 보유 포인트, 게시판 닉네임
- 미니게임 바로가기, 최근 공지, 최근 자료, 교육 뉴스, 내 질문

[공지] 말머리 필터, '정오표' 탭은 교재별로 묶어 표시
[자료실] 내 반 자료만 다운로드
[강의 영상] 내 반 영상 중 만료되지 않은 것만 표시, 새 창으로 열림
[내 성적] 본인 점수와 반 평균만 표시(다른 학생 점수·석차 비공개)

[질답 게시판]
- 질문 유형 선택: 학습질문(사진 필수), 행정문의(사진 선택)
- 제목 형식 [교재-페이지-번호]와 작성 요령 안내문
- 학습질문: 모든 반 학생에게 공개, 작성자는 닉네임만 표시(실명·수험번호·반 비공개)
- 행정문의: 본인과 강사·조교만 열람
- 전체 / 유형별 / 내 질문 탭, 제목·내용 검색, 페이지 나누기(30개 단위)
- 답변 후 추가 질문 2회까지(사진 첨부 가능), 추가 질문 시 답변 대기로 돌아감, "질문 횟수 n/3" 표시
- 답변 표시: "선생님 답변" 또는 "조교 답변 (이름)"
- 답변이 달리기 전의 본인 질문만 삭제 가능

[닉네임]
- 계정 생성 때 '관형어 + 동물'로 자동 부여(예: 달리는 하마), 중복 없음
- 관형어 50개 x 동물 50개. 코알라는 제외(사용자 요청)

[미니게임] 정답은 서버에만 저장, 채점도 서버에서 수행
- 염기 짝 맞추기: 상보 가닥 입력, 난이도 3단계(8/12/16개), 제한 시간 90초, 버튼·키보드 입력
- 샤가프 법칙: 염기 비율·개수 계산 등 5문제, 숫자는 매번 새로 생성
- 통합과학 퀴즈: 8개 단원 문제은행(단원별 6~7문제)에서 5문제, 선택지 순서 무작위, 해설 제공
  단원: 과학의 기초 / 원소의 생성과 주기성 / 화학 결합과 물질의 성질 / 지구시스템 / 역학 시스템 /
        생명 시스템 / 변화와 다양성 / 환경과 에너지
  문제 추가 위치: quiz.py 의 BANK

[포인트]
- 하루 첫 접속 +10P
- 미니게임: 하루 최대 50P
  샤가프·퀴즈: 맞힌 개수만큼 + 만점 2P
  염기 짝 맞추기: (맞힌 개수 / 4) + 만점이면 (난이도 x 2) + 빠르게 만점이면 2
- 강사 수동 지급
- 내역 페이지 있음. 포인트로 교환·구매하는 기능은 없음

5. 보안
==================================================
- 비밀번호: argon2id, 10자 이상 + 영문·숫자·특수문자 중 2종류
- 임시 비밀번호: 저장하지 않고 1회만 표시, 첫 로그인 때 변경 강제
- 로그인 제한: 계정별 5회 실패 시 15분 잠금, IP별 5분 20회. 없는 계정도 같은 응답
- 가입 제한: IP별 1시간 10회
- IP 제한 기록은 메모리에 있어 서버를 재시작하면 초기화됨
- 세션: HttpOnly, SameSite=Lax, 로그인 시 재발급, 미사용 60분 만료, 최대 8시간
- HTTPS 배포 시 Secure 쿠키와 HSTS 적용
- 권한: 서버에서 역할 확인, 학생 조회는 본인 조건 포함
- CSRF 토큰, CSP(인라인 스크립트 금지), 템플릿 자동 이스케이프, 파라미터 바인딩 SQL
- 업로드: 확장자 허용 목록 + 파일 시그니처 검사, 무작위 이름으로 웹 경로 밖 저장, 권한 확인 후 다운로드
- 필드 암호화(Fernet): 학생 연락처, 메모, 상담 기록
- CSV 내보내기 수식 주입 방지, 오픈 리다이렉트 차단
- 비밀키와 암호화 키: instance/.env (최초 실행 때 생성. 암호화 키를 잃으면 암호화 필드 복구 불가)
- 한계: 암호화 키가 DB와 같은 폴더에 있어, 서버 전체가 뚫리면 필드 암호화는 보호가 되지 않음
- 전문 보안 점검은 받지 않음

9. 해결한 문제 (참고)
==================================================
2026-11-01 수정. 학생이 사진을 올린 적이 있으면 계정 삭제, 퇴원 처리, 영구 삭제가 500 오류로 실패하던 문제.
- 원인: files.owner_id 가 users 를 참조해서 파일 소유자인 학생 계정을 지울 수 없었음
- 수정: 계정이 지워지면 owner_id 를 NULL 로 둠(ON DELETE SET NULL). 기존 DB는 앱 시작 때 자동 이전
- 계정 삭제·퇴원: 계정만 삭제. 성적, 질문, 첨부 사진은 유지. 포인트와 접속 기록은 계정과 함께 삭제됨
- 영구 삭제: 학생 기록과 질문·추가 질문 첨부 사진을 DB와 디스크에서 모두 삭제
- 재발 방지 테스트 4개 추가

현재 알고 있는 미해결 오류는 없음. 다만 8번의 "확인하지 못함" 항목은 남아 있음.

10. 배포 진행 상황 (시놀로지 NAS)
==================================================
- 목표: PC를 꺼도 언제나 접속되는 사이트
- 완료: 배포 파일과 zip 준비, Container Manager 설치됨(사용자 응답)
- 미확인: NAS 모델명, DSM 버전(답변이 빈칸이었음)
- 멈춘 지점: 보안 보강 여부 결정 대기. NAS에는 아직 아무것도 올리지 않음

제안만 하고 구현하지 않은 보안 보강
- 강사·조교 2단계 인증(현재 없음. 가장 큰 앱 쪽 빈틈)
- Cloudflare Tunnel: 공유기 포트를 열지 않는 방식. SYNOLOGY.md 는 아직 443 포트 + 리버스 프록시 방식 기준
- 스냅샷과 외부 백업 설정

남은 순서
1) 보안 보강 여부 결정
2) NAS 기본 보안(관리자 2단계 인증, 자동 차단, 방화벽, 업데이트)
3) 파일 올리고 컨테이너 실행
4) 강사 계정 생성
5) 주소, HTTPS, 외부 접속 연결
6) 백업과 최종 확인

==================================================
11. 사용자 결정 사항
==================================================
- 출석 관리 기능은 만들지 않음. 접속 기록은 학생 동기 부여용
- 학부모 기능은 나중에
- 과제 제출·완료 기능은 사용자 요청으로 중단하고 코드 제거
- 퀴즈는 비용 문제로 Claude API 출제를 제거하고 문제은행만 사용. API 키 불필요
- 반 이름은 A, B, C ... 형식. '의대반' 같은 예시 제거
- 강의 영상은 파일 업로드 대신 외부 링크 + 만료일
- 학습질문은 전체 공개(닉네임 표시), 행정문의는 비공개
- 회원가입은 학생만, 반 코드 + 강사 승인
- 모든 안내와 화면 문구는 한국어

참고 영상에서 고르지 않아 넣지 않은 기능
- 선생님 프로필 카드, 행성 키우기(포인트 수집), D-day 응원 글
- 자유 게시판, 신고·차단, 알림함, 마이페이지, 모바일 하단 탭바
