# SEQUENCE — 표지 오브제

정육면체에서 출발해 결정으로 끝나는 유리 오브제. Blender / Cycles 로 모델링하고
렌더한다.

## 왜 Blender 인가

처음 두 번은 이 형태를 레이마칭 SDF 로 만들려 했다. 참고 아트를 보고 거리장
수식을 추측하고, 렌더해 보고, 아니면 다른 프랙탈 계열로 갈아타는 식이었다.
형태를 수식으로 발명하려 한 것이 잘못이었다. 지금은 형태를 직접 만든다.

부수적으로, 유리도 제대로 된다. SDF 버전의 굴절은 내부 반사를 한 번만 계산하는
근사였고 그래서 탁해 보였다. Cycles 는 실제 다중 굴절과 코스틱을 계산한다.

## 구조

참고 아트의 형태 그대로, 세 부분이다.

1. **정육면체** — 따로 떨어져 있는 유리 큐브. 수열의 시작항.
2. **두 가닥** — 공통 축을 감고 도는 두 가닥. 반경이 허리에서 0 이 되어 한
   덩어리로 합쳐지고, 교차 지점마다 벌어진다. 이 벌어짐이 렌즈 모양 구멍의
   정체다. 하나의 띠에 슬롯을 파는 게 아니라, 두 가닥이 만났다 헤어지는
   것이다.
3. **결정** — 작은 판과 블록 210 개를 타원체 안에 뿌리고 복셀 리메시로 하나로
   융합한 뒤, Dissolve 데시메이트로 복셀 계단을 평면 면으로 되돌린다. 이
   마지막 단계가 각진 결정면을 만든다. 리메시만 하면 뭉툭한 덩어리가 된다.

## 재질과 조명

배경색과 조명 환경을 분리한다. World 셰이더에서 Light Path 의 Is Camera Ray 로
갈라, 카메라가 보는 배경은 거의 검게 두고 유리를 비추는 돔은 밝게 유지한다.
합쳐 두면 어두운 표지에서 유리가 크롬처럼 보인다.

색은 Volume Absorption 으로 넣는다. 두꺼운 곳이 진해지고 얇은 곳이 옅어지는 게
표면 색으로는 안 나온다. 축을 따라 청록 → 보라, 결정 끝에서만 다시 청록.

**발광 요소는 없다.** 블룸도 글로우도 넣지 않는다.

## 사용

```
pip install bpy==4.5.14
python3 build.py --view portrait --theme dark --w 630 --h 891 --samples 128 --out out.png
```

`--view` 는 `portrait`(앞표지), `spread`(전개도), `structure`(구조 분해).

카메라는 정사영이고 +Y 를 본다. 따라서 화면상의 대각선은 **Y 축 회전**이고,
Z 축 회전은 깊이 방향으로 돌린다. 정육면체만 화면 대각선 회전을 상쇄해 두어,
기울여도 마름모가 아니라 정육면체로 읽힌다.

## 판형

210 × 297 mm, 책등 15 mm. 전개도 = 435 × 297 mm. 아트보드는 3 px/mm
(1305 × 891 px), 재단선 안쪽 14 mm 안전 영역.
