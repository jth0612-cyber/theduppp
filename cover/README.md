# SEQUENCE — 표지 오브제

정육면체에서 출발해 결정으로 끝나는 유리 오브제. 실시간 레이마칭(WebGL).

## 구조

참고 아트의 형태를 그대로 따른다. 세 부분이다.

1. **정육면체** — 따로 떨어져 있는 유리 큐브. 수열의 시작항.
2. **띠** — 하나의 연속된 단면이 축을 따라 쓸려 가며 비틀리고, 관통 슬롯이
   열렸다 닫히며 두 가닥으로 갈라졌다 다시 합쳐진다. 갈라지는 지점마다
   단면이 부풀어, 그 안에 렌즈 모양 구멍이 생긴다. 낱개의 덩어리가 아니라
   하나의 띠라는 점이 핵심이다.
3. **결정** — 띠 끝에 용접된 각진 결정 클러스터.

## 결정의 생성

회전을 품은 만화경 IFS(kaleidoscopic IFS)다. 폴드 안의 회전이 격자를 월드
축에서 떼어내, 면 방향이 여러 갈래로 흩어진다. 이 회전이 없으면 결정이
아니라 상자를 쌓아 올린 것처럼 보인다 — 축 정렬 폴드로는 아무리 반복을
늘려도 규칙적인 격자나 먼지가 될 뿐이다.

## 재질

배경색과 조명 환경을 분리한다. 어두운 표지에서도 조명 돔은 밝게 유지해야
유리가 크롬처럼 보이지 않는다. 프레넬로 반사와 굴절을 섞고, 내부를 한 번 더
마칭해 두께에 따른 흡수와 채널별 IOR 차이에 의한 색분산을 넣는다.

**발광 요소는 없다.** 블룸도 헤일로도 넣지 않는다. 오브제는 빛을 받을 뿐
스스로 빛나지 않는다.

색은 축을 따라 청록 → 보라로 가고, 결정 끝에서만 다시 청록으로 돌아온다.

## 구성

- `seq3d.js` — 셰이더와 렌더러. `window.SEQ3D.mount(canvas, opts)`.
- `project/*.dc.html` — 아트보드 5종.
- `gen.js` — 아트보드 생성 스크립트.
- `reference/form2.js` — 셰이더의 SDF와 1:1 대응하는 CPU 구현.
  `reference/render2.js` 로 렌더해 눈으로 확인한 뒤 셰이더에 옮긴다.
  `node render2.js portrait 630 891 dark out.png`

재단선 안쪽 14 mm 안전 영역.
