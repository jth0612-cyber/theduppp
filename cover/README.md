# SEQUENCE — 표지 오브제 (cube → snowflake)

정육면체가 단계적으로 결정화되어 눈 결정 구조에 이르는 과정을 유리 재질로
표현한 3D 오브제. 실시간 레이마칭(WebGL) 으로 렌더링한다.

## 구성

- `seq3d.js` — 렌더러. 단일 프래그먼트 셰이더에서 SDF 레이마칭 + 유리(투과/굴절/분산/흡수) 셰이딩.
  `window.SEQ3D.mount(canvas, opts)` 로 마운트, `update(opts)` 로 파라미터 갱신.
- `project/*.dc.html` — 아트보드 6종 (전개도 3안 + 라이트 버전 + 앞표지 단독 2종).
- `project/canvas.json` — 캔버스 인덱스(아트보드 배치).
- `gen.js` — 위 아트보드 생성 스크립트. 판형/가이드/트윅 정의가 한곳에 모여 있다.

## 형태 생성 원리

`crystalDE(z, m)` 의 `m` 이 0 → 1 로 가면서:

1. `m = 0` — 모서리가 살아 있는 순수 정육면체.
2. 멩거(Menger) IFS 폴드가 한 번에 하나씩 페이드인(`mix(z, fold(z), a)`)되어
   면에 구멍이 뚫리고 격자 구조가 생긴다. 최대 4회.
3. 동시에 베이스 솔리드가 정육면체에서 3축 방향으로 뻗는 가늘고 긴 팔
   (`baseDE` 의 `g`) 로 변해, 각 서브큐브마다 결정 가지가 자란다.

체인은 3차 베지에 경로 위에 배치되고, 이웃한 오브제는 `smin` 으로 융합되어
녹아 흐르는 유리 덩어리처럼 이어진다.

## 판형

210 × 297 mm, 책등 15 mm. 전개도 = 435 × 297 mm. 아트보드는 3 px/mm
(1305 × 891 px) 로 작업했고, 재단선 안쪽 14 mm 를 안전 영역으로 표시한다.
